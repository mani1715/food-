# Aura Home Food Platform

A luxury, modern, mobile-first Home Food Marketplace website built strictly using a Black and White design language (`#000000`, `#FFFFFF`, `#E5E5E5`).

## Features

### 1. Customer Experience Portal (14 Views)
- Explore Food page with advanced filters & search
- Food Details page with image lightbox & reviews
- Home Chef profiles & menu showcase
- Cart & Checkout with mock payment methods
- Order tracking timeline & order history
- Saved favorites wishlist & address management
- Help & Support center with interactive ticketing

### 2. Home Chef Experience Portal (8 Views)
- 7-step chef registration wizard
- Live kitchen operations dashboard
- Menu management (add/edit/delete dishes)
- Order fulfillment & status updates
- Revenue analytics & payout history
- Operating hours & kitchen schedule controls

### 3. Admin Experience Portal (9 Views)
- Platform executive dashboard & GMV metrics
- Customer & Chef directory management
- Chef document verification workspace
- Category taxonomy & promotion coupon manager
- Platform reports & analytics

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (Build tool)
- **Tailwind CSS** (Monochrome design system)
- **Framer Motion** (Micro-animations & transitions)
- **Lucide React** (Monochrome icons)
- **React Router v6** (Client-side routing)

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```

4. Run production preview:
   ```bash
   npm run preview -- --host --port 5173
   ```
